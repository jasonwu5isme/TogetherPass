# Together Pass

University of Sydney team project showcase and interactive prototype, reconstructed by Shijie Wu.

- Project introduction: `about.html`
- Interactive prototype: `index.html`
- Chinese by default, with English switching.
- No build step or external dependencies.

## GitHub Pages

Publish `main` from `/ (root)` in Settings → Pages.
The expected public URL after successful deployment is `https://jasonwu5isme.github.io/TogetherPass/`.

This is a team academic concept, not an official Prezzee product. See the project introduction for personal contribution and current status. Original research documents are not included.
